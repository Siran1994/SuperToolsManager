# SuperToolsManager 🛠️

<p align="center">
  <strong>Unity Package Manager (UPM) 规范的开发者通用工具箱管理器</strong>
</p>

## 📖 项目简介
SuperToolsManager 是专为 Unity 开发者打造的轻量级工具箱管理器，提供 UPM Git URL 接入与 `.unitypackage` 双格式支持。

## 📦 安装方式
### 方式一：UPM Git URL 安装（推荐）
在 Unity Package Manager 中点击 `+` -> `Add package from git URL...`，输入：
https://github.com/Siran1994/SuperToolsManager.git

### 方式二：离线安装
直接双击根目录下的 `SuperToolsManager.unitypackage` 导入。
